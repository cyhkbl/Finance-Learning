# 开户

## 券商可定价
1. **佣金（经纪费）**
   - 按成交金额比例（如万几）或最低5元/笔等。
   - 关键点：是否有**最低收费**、是否按**单边**收还是含双边、**不同市场费率是否不同**（A股/港股/美股/期权），是否有**阶梯佣金**（月成交额越高费率越低）
2. **平台费/交易系统使用费**
   - 常见于美股/港股或互联网券商（每笔几美元/几港币）。
   - 是否**按订单笔数**计费（拆单会变贵）。
   - 是否**不同品种不同费率**（ETF/可转债/期权常不同，是否对场内基金/ETF/LOF也免五？）
3. **融资融券利率 / 借券费率（做空费用）**
   - 融资利率（年化%）差异会远大于佣金差异。
4. **资金相关费用**
   - 出入金电汇费、换汇点差、跨境汇款中转行费用、入金最低金额要求等。
5. **账户服务费**
   - 账户管理费、闲置费、行情费（L1/L2）、最低资产要求不达标的收费。

## 基本固定

- **印花税**
- **交易征费/交易费/清算费/过户费**
- **SEC/FINRA等监管费**

## 成交质量

- 是否支持更优路由/智能路由
- 是否经常出现“挂单不成交/成交价偏差”
- 是否提供**分时成交回溯、订单执行报告**
