# 交易体系

## 交易风格

*   **价值投资：** 深度基本面分析，寻找被低估的优质公司，长期持有（数年甚至更久），陪伴公司成长，赚取企业盈利增长和估值修复的钱。代表：巴菲特。
*   **成长股投资：** 关注盈利高速增长、未来发展空间巨大的公司，愿意为高增长支付较高估值，赚取业绩增长的钱。风险在于高增长未能持续或被证伪。
*   **趋势交易：** 信奉“趋势为王”，利用技术分析识别并跟随趋势（上升趋势做多，下降趋势做空或观望），在趋势确立时入场，趋势结束时离场。适合中短线。
*   **波段操作：** 在股价的波动中（如一个上升波段或下降波段）进行高抛低吸，持仓周期数天到数周。
*   **短线交易/日内交易：** 持仓时间很短（日内或几天），利用技术分析、盘口信息、市场情绪进行高频操作。对时间精力、技术、纪律、手续费敏感度要求极高，风险巨大。
*   **量化交易：** 利用数学模型和计算机程序进行交易决策和执行。

## 交易计划

*   **选股/选时：** 买入什么股票（或指数基金ETF）？在什么条件下买入？
*   **单笔风险控制：** 每次交易最多愿意承担多少比例的本金损失？这决定了该买多少股（仓位大小）。
*   **总仓位控制：** 不同市场环境下（牛市、熊市、震荡市），投入股市的总资金比例是多少？避免满仓操作。
*   **分散投资：** 不要把所有资金押注在一两只股票上。分散到不同行业、不同市值的公司，降低非系统性风险。
*   **买入策略：** 一次性买入？分批建仓？金字塔式加仓（价格越低买的越多）？
*   **卖出策略**
    *   **止损：** 预先设定一个可以接受的最大亏损价格或百分比，一旦触及，无条件卖出。这是控制风险、防止亏损扩大的生命线！
        * 常见止损方法：固定比例止损（如-8%）、支撑位下方止损、技术形态破位止损、移动止损（随着股价上涨提高止损位）。
    *   **止盈：** 设定目标盈利位或根据趋势变化、技术信号、基本面变化卖出锁定利润。
        * 常见止盈方法：目标价位止盈、趋势反转信号止盈、移动止盈（跟随趋势上移止盈点）、分批止盈。
*   **持有策略：** 买入后如何管理？是否需要根据情况调整仓位（加仓/减仓）？如何应对市场波动？
*   **风险管理**
    *   严格执行交易计划，特别是止损纪律。
    *   永不满仓，保留一部分现金以应对极端情况或捕捉新机会。
    *   定期审视持仓，评估基本面是否发生变化。
    *   避免情绪化交易（追涨杀跌）。

## 记录与复盘

*   **交易日志：** 记录每一笔交易的：
    *   买入/卖出理由（依据的分析方法、信号）
    *   交易日期、价格、数量
    *   计划止损位、止盈位
    *   实际执行情况（是否按计划？）
    *   盈亏结果
    *   **最重要的：** 交易时的心理状态、反思
*   **定期复盘：** 每周/每月回顾交易日志，分析盈亏来源，评估策略有效性，不断优化。
