# 套利

判断是否可套利，核心看的是**场内价格 vs 基金份额的真实价值（IOPV/参考净值）**以及**申赎与交易摩擦是否允许把价差兑现**。

LOF场内交易价格可能相对其净值出现**溢价（价格高于净值）**或**折价（价格低于净值）**。套利（申赎套利/折溢价套利）成立的必要条件是：

- **场内价格 - 可实现净值（或IOPV）** 的偏离足够大
- 能通过**申购/赎回 + 场内卖出/买入**把偏离套利
- 扣除所有成本后还有正收益

## 观察指标

- 当日/实时 **IOPV**
- 场内价格相对IOPV的 **溢价率/折价率**
- 申购赎回规则（T日确认、是否现金替代、是否暂停申赎等）

## 风险

### T+1/T+2确认 + 时差

海外资产定价、基金净值计算、申赎确认往往有**时差**。在A股时段看到的“溢价/折价”，可能对应的是海外上一交易时段价格，**下单到申赎确认期间标的又变了**，价差不再存在，反而可能亏损。这是典型的**基差/隔夜风险**。

### 申赎限制、暂停或门槛高

LOF理论上可申赎，但原油类产品历史上经常出现：
- **暂停申购/暂停赎回**
- **大额申购限制**
- 申赎成本较高或规则复杂
一旦申赎链条不通，场内折溢价就会“飘”，**套利者无法把价差锁定**。

### 交易摩擦

- 场内买卖佣金、印花税（基金一般无印花税，但交易费用、券商佣金存在）
- 申购赎回费（若有）
- 价差/冲击成本（成交不一定在你看到的价位）
- 海外标的波动、汇率波动带来的隐含风险

## 可操作指标

1. **场内溢价率/折价率显著**（例如持续明显偏离IOPV）
2. **申购/赎回正常**，且你具备申赎资格与通道
3. 标的在申赎确认周期内的波动风险可控
4. 扣除费用与滑点后仍有利润空间

## 操作方法

1. 执行申购：通过券商或基金平台，以基金的单位净值（收盘价） 为基准，场外申购该LOF基金。
2. 等待份额到账：T日申购，基金份额通常在 T+2 或 T+3 个交易日才会到达你的场内账户。
3. 场内卖出：份额到账后，立即在证券交易所（场内）以当前的交易价格卖出。
