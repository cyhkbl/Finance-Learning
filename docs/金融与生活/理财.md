# 理财

## 理财前准备
    
- 预算：每月固定支出（学费、住宿、水电、通讯）和可变支出（餐饮、娱乐）
        
- 每月预留理财存量：月可支配收入-必要支出
        
- 使用记账工具
        
- 建立紧急预备金（3–6个月生活费）放在随时可取的高流动性账户（如高校定向学生活期、货币基金）

## 资产配置

- 流动性储备：40%。高流动储蓄（货币基金、余额宝等）流动性高、可随取随用，收益略高于银行活期
- 低风险固定收益：30%。银行定期、小额理财、短期债券基金收益稳定、波动小，但流动性一般，要注意期限匹配
- 中低风险权益类：20%。指数型ETF（如沪深 300、标普 500 ETF）分散度高、费用低、长期看具备不错收益，但短期有波动
- 学习与成长投资：10%。投资自己（技能、证书），提升未来的赚钱能力
